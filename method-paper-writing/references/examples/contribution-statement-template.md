# Contribution Statement Template (Method Papers)

Audience-sorted contribution paragraphs closing the introduction. Methodological comes first, stated as a capability. Content is generic and invented.

```latex
% Methodological: a capability the tool makes possible
% Substantive: what we now know about the phenomenon
% Managerial / policy: what an actor can now do
% Each paragraph ends with an "Unlike [closest work]" contrast
```

## Skeleton

1. **Methodological.** `We provide a [model / framework / algorithm] that makes it possible to [capability]. Unlike [closest work], which [limitation, stated respectfully], ours [difference].` State a capability, not a technique name.
2. **Substantive.** `We show that [phenomenon] arises because [mechanism], which [reframes / settles] [question]. Unlike [closest work], we [what it could not show].`
3. **Managerial / policy.** `For [actor], our results imply [guideline with a number]. Unlike [closest work], we [counterfactual or deployment claim it could not make].`

## Two-part statement rule

State the technical answer first, then the business perspective, and end in the simple rule or algorithm an actor can run (for example, "bid below your valuation by an amount that rises with the option value of waiting").

## Rules

1. Contributions say what the field can now do; findings say what is true. Do not restate findings.
2. Describe the closest work by what it cannot do, respectfully, as a capability or question, not a resource.
3. Order by audience, methodological first.

## Checklist

1. Is the methodological paragraph a capability rather than a technique name?
2. Does each paragraph end with a precise, respectful "Unlike…" contrast?
3. Does the two-part statement end in a rule an actor can run?
4. Are findings absent from the contribution paragraphs?
