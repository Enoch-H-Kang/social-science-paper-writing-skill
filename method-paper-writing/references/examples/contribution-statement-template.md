# Contribution Statement Template (Method Papers)

Audience-aware contribution paragraphs closing the introduction. Lead with the paper's headline contribution. Content is generic and invented.

```latex
% Methodological: a capability the tool makes possible
% Substantive: what we now know about the phenomenon
% Managerial / policy: what an actor can now do
% Add a closest-work contrast only when a source supports the difference
```

## Skeleton

1. **Methodological.** `We provide a [model / framework / algorithm] that makes it possible to [capability]. [Optional sourced contrast: Compared with [closest work], this addresses [specific question].]` State a capability, not a technique name.
2. **Substantive.** `We show that [phenomenon] arises because [mechanism], which [reframes / settles] [question]. [Optional sourced contrast.]`
3. **Managerial / policy.** `For [actor], our results imply [supported guideline or consequence, with a number only if relevant]. [Optional sourced contrast.]`

## Two-part statement rule

State the technical answer first, then the business perspective, and end in the simple rule or algorithm an actor can run (for example, "bid below your valuation by an amount that rises with the option value of waiting").

## Rules

1. Contributions say what the field can now do; findings say what is true. Do not restate findings.
2. When contrasting closest work, cite a source and describe the precise difference respectfully, as a capability or question.
3. Order by the paper's headline, then the other relevant audiences.

## Checklist

1. Is the methodological paragraph a capability rather than a technique name?
2. Is any closest-work contrast precise, respectful, and supported by a source?
3. Does the two-part statement end in a rule an actor can run?
4. Are findings absent from the contribution paragraphs?
